# Fazı bitir

1. docs/gelgel-belgeleri.md Bölüm 6'da bu fazın "bitti sayılma ölçütü"nü bul. Kullanıcıya ölçütü hatırlat ve telefonda test edip etmediğini sor. Kullanıcı "evet, çalışıyor" demeden devam etme.
2. docs/ilerleme.md dosyasına bu faz için şu başlıklarla ekleme yap: Faz adı ve tarih, Yapılanlar, Alınan kararlar, Bilinen eksikler.
3. Değişiklikleri git commit ile kaydet. Mesaj: "Faz X tamamlandı: [kısa özet]".
4. Kullanıcıya sade Türkçeyle şunu söyle: "Faz X kapandı. Sıradaki faza geçmek için önce /clear yaz, sonra /sonraki-faz yaz."
